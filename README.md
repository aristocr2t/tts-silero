# tts-silero

Русский синтез речи для терминала на [Silero](https://github.com/snakers4/silero-models).
Он читает текст вслух, а перед этим — самое интересное — переписывает его так, чтобы
синтезатор произносил всё правильно: числа, единицы измерения, латинские слова, символы
и ударения.

```bash
voice "Задержка 10 мс, память 8 GB, цена 1500 руб/шт"
```
```text
задержка д+есять миллисек+унд, п+амять в+осемь гигаб+айт, цен+а полтор+ы т+ысячи рубл+ей за шт+уку
```

## Почему одного Silero мало

Silero — хороший русский голос, но он проглатывает именно те части реального текста,
в которых заключён смысл:

| Вход | Что скажет наивный конвейер | Что скажет этот инструмент |
|---|---|---|
| `10 мс` | `10 эм-эс` (число потеряно) | `десять миллисекунд` |
| `1500 руб` | `одна тысяча пятьсот руб` | `полторы тысячи рублей` |
| `5 кг/м³` | `пять кг/м³` (слэш потерян) | `пять килограммов на кубический метр` |
| `tts` | падение: `Failed to parse SSML` | `ти-ти-эс` |
| `«Оки» = «Окей»` | слова слипаются | `«Оки» равно «Окей»` |
| `замок` | одно фиксированное чтение | `з+амок` / `зам+ок` по контексту |

Длина текста не ограничена: `voice --file war-and-peace.txt` синтезирует кусок за куском
и сразу пишет их в один файл, поэтому целая книга — это один запуск, один файл,
одно проигрывание.

## Требования

- macOS, Linux или Windows с `ffmpeg` (Windows: `winget install ffmpeg`)
- Python 3.10+ (установщик собирает virtualenv; `uv` используется, если он есть)
- ~1 ГБ на диске для torch и моделей ruaccent
- `libsndfile`, если колесо `soundfile` не приносит её с собой (Debian/Ubuntu: `sudo apt install libsndfile1`)
- Хватает CPU; модели ruaccent один раз скачиваются с Hugging Face

## Установка

### macOS и Linux

```bash
curl -fsSL https://raw.githubusercontent.com/aristocr2t/tts-silero/main/install.sh | bash
```

Установщик клонирует репозиторий в `~/.local/share/tts-silero`, создаёт virtualenv,
ставит зависимости и делает ссылку `~/.local/bin/voice`. Раскладку можно изменить через
`TTS_SILERO_DIR`, `TTS_SILERO_BIN`, `TTS_SILERO_REF`, а готовый интерпретатор подключить
через `TTS_SILERO_PYTHON=/path/to/python`. `TTS_SILERO_SOURCE=/path/to/checkout` ставит
из локальной рабочей копии вместо клонирования.

Установка вручную:

```bash
git clone https://github.com/aristocr2t/tts-silero.git
cd tts-silero
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
ln -s "$PWD/bin/voice" ~/.local/bin/voice
```

### Windows

```powershell
irm https://raw.githubusercontent.com/aristocr2t/tts-silero/main/install.ps1 | iex
```

Установщик клонирует репозиторий в `%LOCALAPPDATA%\tts-silero`, создаёт virtualenv,
ставит зависимости и кладёт запускатор `voice.cmd` в `%LOCALAPPDATA%\Microsoft\WindowsApps`
(этот каталог уже в `PATH`). Переменные те же, что в `install.sh`:
`TTS_SILERO_DIR`, `TTS_SILERO_BIN`, `TTS_SILERO_REF`, `TTS_SILERO_PYTHON`,
`TTS_SILERO_SOURCE`.

Установка вручную:

```powershell
winget install ffmpeg
winget install Git.Git
git clone https://github.com/aristocr2t/tts-silero.git $HOME\Repos\tts-silero
cd $HOME\Repos\tts-silero
py -3 -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\bin\voice.cmd "привет, это проверка"
```

`bin\voice.cmd` выбирает интерпретатор в таком порядке: `VOICE_PYTHON`,
`.venv\Scripts\python.exe`, `python`, `py -3`. Чтобы вызывать просто `voice`, добавьте
`bin` в `PATH` или создайте обёртку `voice.cmd` в каталоге, который уже есть в `PATH`.
Проигрывание идёт через `winsound` (WAV), поэтому отдельный плеер не нужен; `ffplay`
используется, когда больше ничего нет.

## Использование

```bash
voice "обычная фраза"                     # озвучить
voice --file chapter.txt                  # длинный текст целиком
printf 'текст из stdin' | voice -         # текст из stdin
voice --save "сохрани это"                # wav + mp3 в $TMPDIR/voice, печатает путь к mp3
voice --save=~/voice-out "сохрани это"    # wav + mp3 в свой каталог
voice --print "1500 руб/шт"          # показать текст с акцентом и озвучить
voice -P --no-play "1500 руб/шт"          # только текст, без синтеза и звука
voice -P --raw "т+ы уж+е *сд+елал* п+уш?" # своя разметка без обработки
voice --voice eugene --tempo 1.2 "быстрее" # другой голос, быстрее, тон тот же
```

### Опции

| Опция | Значение | По умолчанию |
|---|---|---|
| `--voice <name>` | `eugene`, `aidar`, `baya`, `kseniya`, `xenia` | `eugene` |
| `--rate <r>` | `x-slow`, `slow`, `medium`, `fast`, `x-fast` | `medium` |
| `--pitch <p>` | `x-low`, `low`, `medium`, `high`, `x-high` | `medium` |
| `--sr <n>` | частота дискретизации: `8000`, `24000`, `48000` | `48000` |
| `--tempo <x>` | скорость без изменения тона, `0.5`–`2.0` | `1` |
| `--pitch-shift <x>` | поднимает тон и форманты вместе, `1.0`–`1.2` | `1` |
| `--chunk <n>` | символов в куске синтеза, `100`–`900` | `900` |
| `--pause <s>` | тишина после проигрывания | `0.5` |
| `--save[=dir]` | сохранить wav и mp3; голый `--save` берёт каталог по умолчанию, `--save=DIR` — указанный | `$TMPDIR/voice` |
| `--file <path>` | прочитать текст из файла | — |
| `-P`, `--print` | напечатать текст, который получит синтезатор (с акцентом `*…*`), и продолжить озвучку | — |
| `--raw` | текст уже размечен: без нормализации, без ruaccent и без автоакцента | — |
| `--no-play` | не проигрывать; с `--save` только сохранить, без `--save` аудио не создаётся | — |
| `-h`, `--help` | краткая справка | — |

### Переменные окружения

| Переменная | Значение | По умолчанию |
|---|---|---|
| `VOICE_SPEAKER` | голос по умолчанию | `eugene` |
| `VOICE_TEMPO` | темп по умолчанию | `1` |
| `VOICE_PITCH_SHIFT` | подъём тона по умолчанию | `1` |
| `VOICE_CHUNK_CHARS` | размер куска по умолчанию | `900` |
| `VOICE_SAVE_DIR` | каталог сохранения по умолчанию | `$TMPDIR/voice` |
| `VOICE_PYTHON` | интерпретатор с зависимостями | `.venv/bin/python` |
| `VOICE_ACCENT` | `0` отключает расстановку ударений | `1` |
| `VOICE_ACCENT_MODEL` | размер модели омографов ruaccent | `turbo3.1` |
| `VOICE_ACCENT_DEBUG` | `1` печатает, почему ruaccent недоступен | выкл |
| `VOICE_CONFIG` | путь к конфигу своего произношения | `~/.config/tts-silero.json` |
| `VOICE_BREAK_MS` | необязательная пауза после латинского слова, миллисекунды | `0` (выкл) |
| `VOICE_LOCK_DIR` | лок очереди проигрывания | `$TMPDIR/voice.lock` |

### Своё произношение

Слова, специфичные для вашей работы, живут в вашем конфиге, а не в этом репозитории:

```json
// ~/.config/tts-silero.json
{
  "voice": {
    "speaker": "eugene",
    "rate": "medium",
    "pitch": "medium",
    "sample_rate": 48000,
    "tempo": 1,
    "pitch_shift": 1,
    "chunk": 900,
    "pause": 0.5
  },
  "words": {
    "geekideas": "гикайдиас",
    "гикайдеас": "гик айд+иас"
  },
  "replacements": [
    ["кованый замок", "кованый зам+ок"]
  ]
}
```

- `voice` — значения по умолчанию для каждого запуска, так что CLI можно вызывать без
  аргументов. Приоритет: аргументы командной строки, затем переменные окружения, затем
  эта секция, затем встроенные значения. Значения вне документированных диапазонов
  пропускаются с замечанием в stderr.
- `words` — своё произношение для латинских слов, аббревиатур и русских слов; ключ
  сравнивается без учёта регистра целым словом и перекрывает встроенные словари.
- `replacements` — регулярные выражения по русскому тексту, применяются до движка
  ударений; `+` помечает ударный гласный.

Файл необязателен и перечитывается на ходу: отсутствующий или сломанный конфиг
сообщается в stderr и игнорируется. Битое регулярное выражение в `replacements`
пропускается отдельно, с одним замечанием, поэтому остальной конфиг продолжает работать.
`VOICE_CONFIG=/path/to/file.json` указывает на другой файл.

## Как это работает

```text
bin/voice (POSIX)  bin/voice.cmd (Windows)
       └───────────────┬───────────────┘
                  tts.cli
текст ─┬─ свои правила произношения ─ твёрдое «тэ»: тест -> тэст
       ├─ потерянные символы ─────── + = == != <= >= → &
       ├─ числа ──────────────────── 2024, 5-го, 21%, -3,5, 15к
       ├─ единицы ────────────────── 10 мс, 5 кг/м³, 1500 руб/шт, 8 GB
       ├─ латиница ───────────────── tts, ssh, bash, ffmpeg (IPA -> кириллица)
       └─ ударения по контексту ──── ruaccent: з+амок / зам+ок
                 │
          Silero (кусок за куском) ── один wav ── темп/тон ── проигрывание
```

Модули в `lib/tts`:

| Модуль | Ответственность |
|---|---|
| `cli.py` | аргументы, приоритет настроек, очередь проигрывания, весь запуск |
| `media.py` | поиск ffmpeg, темп и тон, сохранение и проигрывание |
| `numbers.py` | количественные, порядковые, дроби, проценты, «полтора» |
| `units.py` | единицы измерения, род и падеж, составные единицы |
| `latin.py` | отображение IPA, словари произношения, аббревиатуры, транслит |
| `operators.py` | символы, которые синтезатор молча выбрасывает |
| `accent.py` | необязательные ударения по контексту через ruaccent, с тихим откатом |
| `chunks.py` | деление длинного текста по границам предложений |
| `normalize.py` | конвейер, который связывает всё перечисленное |
| `synth.py` | синтез Silero, один wav на кусок |
| `settings.py` | значения `voice` по умолчанию из пользовательского конфига |
| `config.py` | сам пользовательский конфиг: слова, замены, voice |

## Разработка

```bash
bash -n bin/voice                              # синтаксис shell
bash -n install.sh                             # синтаксис shell
PYTHONPATH=lib python -m unittest discover -s tests -v
```

Набор тестов проверяет только нормализацию текста, поэтому он запускается без torch
и моделей. CI прогоняет те же команды на каждый push.

## Ограничения

- Только русский: целевые голоса Silero — русские, латинский текст транслитерируется.
  Без транслитерации модель падает на первом же латинском символе с `Failed to parse SSML`,
  а не читает его как-нибудь — поэтому `--raw` с латиницей тоже не сработает.
- Ударения — по возможности. ruaccent верно разбирает большинство омографов, но
  `кованый замок` и `орган` всё ещё зависят от контекста, который он не разрешает
  полностью. Добавьте пару в `lib/tts/latin.py` (`WORDS`, `ACRONYMS`, `pronounce_russian`)
  или настройте `VOICE_ACCENT_MODEL`, когда конкретное слово важно.
- Один голос на запуск; длинные тексты синтезируются последовательно на CPU.
- Очередь проигрывания держится только пока голос слышен плюс хвост `--pause`, поэтому
  параллельные вызовы синтезируют одновременно, а не ждут друг друга.
- Диапазоны сохраняют дефис (`10-15 мс` читает тире как паузу), а случайные символы
  вроде `#`, `*`, `/`, `@` остаются на усмотрение движка.
- SSML `<break>` после латинских слов доступен (`VOICE_BREAK_MS`), но он выравнивает
  интонацию всей фразы, поэтому по умолчанию выключен.
- Тип интонации Silero выбирает сама по знаку препинания и по структуре предложения
  (`?`, `!`, вопросительное слово, «или», хвостик вроде «правда»). Извне мы его не
  переопределяем: свои подстановки на слух давали лишнюю акцентность.
- Проигрывание использует `afplay` на macOS, `winsound` на Windows, `ffplay` как запасной
  вариант. Если плеера нет совсем, `--save` сохраняет аудио и печатает путь; без `--save`
  команда останавливается до синтеза с подсказкой, а не завершается молча.
